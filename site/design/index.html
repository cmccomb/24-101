In a physical diagram, red identifies heated components, blue identifies flowing fluid, and ochre identifies sunlight. Label those roles directly. Use text and line style to distinguish states; a requirement shortfall must be understandable without color.

05

Interaction should reveal a relationship.

This specimen runs the same printer model as the lab. Change speed while holding bead geometry and nozzle temperature fixed. The specimen uses a 20 W exercise budget to make the constraint visible.

Use an orthographic camera to explain geometry. Use animation for mechanisms or transport, with a visible pause control and reduced-motion support. Keep quantitative claims in calculations and plots rather than implying that illustrative motion is calibrated.

06

One token source keeps the language consistent.

Design tokens define the shared colors, typography, spacing, layout and timing. They generate both the CSS variables and the 3D material palette. This reference uses the same components as the lab.

Spacing follows 4, 8, 12, 16, 24, 32, 48, 64 and 96 px. Borders are square. Emphasis uses a restrained red rule. Sources, units and model limitations remain part of the evidence.
